# 🏡 Smart Village Management System

A standalone desktop-friendly, responsive web application for rural village governance and citizen services.

Built with Java (Spring Boot), HTML5, CSS3, JavaScript, Bootstrap 5 and MySQL.

## 🌟 Key Features

- Dual Role Authentication: Citizen and Admin.
- Citizen Portal: Complaints, government schemes, agriculture, utilities and emergency services.
- Admin Portal: Citizen management, complaint resolution, scheme approvals and reports.

## 📁 Page Map

### Citizen Portal
1. Citizen Dashboard
2. My Profile
3. Government and Rural Services
4. Report a Problem
5. Complaints and Application Status
6. Agriculture and Farming Services
7. Village News
8. Utility Services
9. Emergency Contacts
10. Logout

### Admin Portal
1. Admin Dashboard
2. Citizen Management
3. Complaint Management
4. Application Management
5. Agriculture Management
6. Utilities Management
7. Village News
8. Reports and Analytics
9. Emergency Notices
10. Logout

## 🗄️ Database Setup

Database: smart_village_db

Username: root

Password: Configure your own local MySQL password.

Port: 3306

Never publish database passwords or other private credentials in this repository.

## 🚀 How to Build and Run

### Prerequisites
- JDK 17 or Java 21+
- Apache Maven 3.6+

### Run Application

```bash
mvn clean compile
mvn spring-boot:run
